# Sources for a personal library of professional coding skills

For project goals and instructions for continuing in a new conversation, read [PROMPT.md](PROMPT.md).

Initial research pass: **2026-09-18**. Scope: broadly applicable software engineering, with examples from several languages and ecosystems.

This is a source map: **where we could learn a useful pattern, what that pattern might help with, and why the source deserves attention**. The pattern mappings and context limits are proposed judgments for this library. They still need examination against concrete examples before becoming skills.

## How to read the evidence

| Signal | Meaning | What it establishes |
| --- | --- | --- |
| **Award** | A named award, with the awarding organization's record. | External recognition of the specified system or paper; the award's scope matters. |
| **Survey** | Developers report wanting to continue using a technology. | Evidence of user satisfaction within that survey's respondents. |
| **Endorsement** | An identifiable practitioner recommends a source. | A traceable recommendation; author-hosted testimonials are labeled. |
| **Practice** | Authors or maintainers explain a technique, with examples or experience. | A promising candidate with inspectable reasoning; independent recognition remains to be collected. |

The [2025 Stack Overflow survey](https://survey.stackoverflow.co/2025/technology) defines “admired” as having used a technology and wanting to continue. The [2024 State of JavaScript survey](https://2024.stateofjs.com/en-US/libraries/) defines retention as users' willingness to use a library again. These are dated, self-selected samples. Neither metric measures how pleasant a project's internals are to maintain, or proves that a particular pattern caused its score. GitHub stars and download counts alone are insufficient for inclusion.

Research depth so far: public articles, documentation, award records, survey results, book descriptions/excerpts, and selected repository files identified in the extraction notes. Other repository links remain entry points for later inspection; this work does not claim full book reviews or codebase audits. **Practice** entries are explicitly provisional under the recognition criterion.

**Access** describes the linked material, initially checked on 2026-09-18; later checks are dated in the extraction notes below. A paid full book does not mean its principles are unavailable: free articles, summaries, or excerpts are identified separately. **Local skill(s)** links the skills created in this library; **—** means no skill has been extracted yet, not that the source is inaccessible.
